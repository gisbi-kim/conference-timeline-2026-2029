# 2026–2029 주요 학회 타임라인

로보틱스와 CV·ML·AI 분야의 주요 학회 개최 일정과 지역을 한눈에 비교하는 정적 타임라인입니다.

- 기준일: 2026년 9월 9일
- 지역별 색상 구분
- 종료된 일정 회색 표시
- 미공개 일정은 예년 개최 시기를 기준으로 TBA 배치
- 해당 연도 홈페이지 또는 학회·개최기관의 공식 발표가 확인된 일정은 링크 활성화
- 연도 경계를 벗어나지 않도록 일정 셀 자동 보정

## 2026-09-09 확인 및 갱신

기존 외부 링크 30개를 점검했습니다. 일반 HTTP 요청 29개는 200 응답이며, SIGGRAPH Asia는 자동 요청에 403을 반환하지만 실제 Chrome에서는 정상 표시됩니다. 추가한 SIGGRAPH Asia 2027 발표 링크도 Chrome에서 확인했습니다. 총 94개 일정 중 55개를 공식 출처로 연결합니다.

- [SIGGRAPH Asia 2027](https://asia.siggraph.org/2026/about-the-event/siggraph-asia-2027/): Tokyo International Forum, 2027-11-30–12-03.
- [CVF 개최지 목록](https://www.thecvf.com/?page_id=100): WACV 2028·2029 Waikoloa 반영. ICCV 2029는 현재 공식 목록이 TBD이므로 기존 Dubai 확정 표시를 TBA로 수정.
- [RSS](https://roboticsconference.org/): 2027 Athens, 7월 6–11일 반영.
- [CVPR 2027](https://cvpr.thecvf.com/Conferences/2027): 종료일을 6월 24일에서 25일로 수정.
- [ICML Future Meetings](https://icml.cc/Conferences/FutureMeetings): 2027 South America 반영; 도시·날짜는 미공개.
- [CoRL 2026](https://2026.corl.org/): 공식 링크와 JW Marriott Austin, Hilton Austin, Bass Hall 추가.
- [ICRA 2028](https://www.ieee-ras.org/event/2028-ieee-international-conference-on-robotics-and-automation-icra-64236/): Expo Guadalajara 추가.
- [IROS 2028 개최기관 발표](https://www.besydney.com.au/media/v4wpfp31/besydney-media-release-sydney-attracting-ai-events-iros.pdf): ICC Sydney 추가.
- [ECCV 2026](https://eccv.ecva.net/Conferences/2026/Venues), [3DV 2027](https://3dvconf.github.io/2027/), ICRA 2026, iSpaRo 2026, ITSC 2026, ICCAS 2026, SIGGRAPH Asia 2026, ICLR 2026, ICML 2026의 공식 행사장 정보 보완.

ICLR 2027은 공식 본문이 여전히 California 및 venue 미공개로 안내하므로 도시·행사장을 추정하지 않았습니다. 이미지 대체 텍스트만으로 개최지를 확정하지 않습니다.

## 2026-09-13 ICRA 2028 개최지 갱신

사이트 관리자가 전달한 개최지 변경 소식에 따라 ICRA 2028을 Rio de Janeiro, Brazil로 수정하고 남미 색상을 적용했습니다. 이전 행사장 Expo Guadalajara 표시는 삭제했습니다. 공개 IEEE 행사 페이지에는 아직 이전 개최지가 표시되어 있으며, 날짜는 기존 2028-05-15–19를 유지했습니다.
