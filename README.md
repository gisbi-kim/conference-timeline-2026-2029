# 2026–2030 주요 학회 타임라인

로보틱스와 CV·ML·AI 분야의 주요 학회 개최 일정과 지역을 한눈에 비교하는 정적 타임라인입니다.

- 최근 부분 갱신: 2026년 11월 16일 (전체 일정의 일괄 재검증을 의미하지 않음)
- 지역별 색상 구분
- 종료된 일정 회색 표시
- 미공개 일정은 예년 개최 시기를 기준으로 TBA 배치
- 해당 연도 홈페이지 또는 학회·개최기관의 공식 발표가 확인된 일정은 링크 활성화
- 연도 경계를 벗어나지 않도록 일정 셀 자동 보정

## 2026-09-09 확인 및 갱신

기존 외부 링크 30개를 점검했습니다. 일반 HTTP 요청 29개는 200 응답이며, SIGGRAPH Asia는 자동 요청에 403을 반환하지만 실제 Chrome에서는 정상 표시됩니다. 추가한 SIGGRAPH Asia 2027 발표 링크도 Chrome에서 확인했습니다. 총 94개 일정 중 55개를 공식 출처로 연결합니다.

- [SIGGRAPH Asia 2027](https://asia.siggraph.org/2026/about-the-event/siggraph-asia-2027/): Tokyo International Forum, 2027-11-30–12-03.
- [CVF 개최지 목록](https://www.thecvf.com/?page_id=100): WACV 2028·2029 Waikoloa 반영. ICCV 2029는 현재 공식 목록이 TBD이므로 기존 Dubai 확정 표시를 TBA로 수정.
- [RSS](https://roboticsconference.org/): 2027 Athens, 7월 6–11일 반영.
- [CVPR 2027](https://cvpr.thecvf.com/Conferences/2027): 종료일을 6월 24일에서 25일로 수정.
- [ICML Future Meetings](https://icml.cc/Conferences/FutureMeetings): 2027 South America 반영; 도시·날짜는 미공개.
- [CoRL 2026](https://2026.corl.org/): 공식 링크와 JW Marriott Austin, Hilton Austin, Bass Hall 추가.
- [ICRA 2028](https://www.ieee-ras.org/event/2028-ieee-international-conference-on-robotics-and-automation-icra-64236/): Expo Guadalajara 추가.
- [IROS 2028 개최기관 발표](https://www.besydney.com.au/media/v4wpfp31/besydney-media-release-sydney-attracting-ai-events-iros.pdf): ICC Sydney 추가.
- [ECCV 2026](https://eccv.ecva.net/Conferences/2026/Venues), [3DV 2027](https://3dvconf.github.io/2027/), ICRA 2026, iSpaRo 2026, ITSC 2026, ICCAS 2026, SIGGRAPH Asia 2026, ICLR 2026, ICML 2026의 공식 행사장 정보 보완.

ICLR 2027은 공식 본문이 여전히 California 및 venue 미공개로 안내하므로 도시·행사장을 추정하지 않았습니다. 이미지 대체 텍스트만으로 개최지를 확정하지 않습니다.

## 2026-09-13 ICRA 2028 개최지 갱신

사이트 관리자가 전달한 개최지 변경 소식에 따라 ICRA 2028을 Rio de Janeiro, Brazil로 수정하고 남미 색상을 적용했습니다. 이전 행사장 Expo Guadalajara 표시는 삭제했습니다. 공개 IEEE 행사 페이지에는 아직 이전 개최지가 표시되어 있으며, 날짜는 기존 2028-05-15–19를 유지했습니다.

## 2026-11-16 공식 발표 반영

- [IROS 2029 · 테네시대학교 공식 발표](https://tickle.utk.edu/bme/news/tan-elected-as-general-chair-for-ieee-rsj-international-conference/): Anaheim, California, USA. 날짜·세부 행사장은 미공개. 타임라인의 월 위치는 예년 기준 추정이며 개최일을 뜻하지 않습니다.
- [IFAC World Congress 2029](https://ifac-control.org/conferences/24th-ifac-world-congress/): Amsterdam, Netherlands, 2029-07-08–13, Amsterdam RAI Convention Centre. [2026 부산](https://ifac-control.org/conferences/23rd-ifac-world-congress-in-busan/), 8/23–28, BEXCO도 추가했습니다. World Congress는 3년 주기이므로 2027·2028에는 해당 행사가 없습니다.
- [ICML 2027](https://icml.cc/Conferences/2027): Rio de Janeiro, Brazil, 2027-07-31–08-06, Riocentro. 7/31 Expo부터 8/5–6 Workshops까지의 전체 일정입니다.
- CoRL 2026, iSpaRo 2026, ICCAS 2026을 종료 표시로 갱신했습니다.
- 11/16 이전에 끝난 모든 행사는 회색 배경과 날짜 앞 `종료 ·` 문구로 표시합니다. 종료 상태는 위 기준일의 스냅샷이며 자동 갱신하지 않습니다.
- 총 27개 학회, 28개 행(OCEANS 권역별 2행), 104개 일정입니다. 다른 항목은 이전 확인 내용을 유지합니다.

## 구조 및 확인 방법

별도 빌드 없이 `index.html`을 브라우저에서 열면 됩니다. 데이터·스타일·가로 드래그 및 연도 내 위치 보정 스크립트가 이 파일에 들어 있습니다. `.nojekyll`은 GitHub Pages의 정적 파일 배포용입니다.

수정할 때는 공식 학회·학회 주관기관·개최기관 발표를 확인하고, 해당 일정의 링크·표시 문구·접근성 설명·지역 색상·연도 위치를 함께 갱신합니다. 부분 갱신 범위와 근거는 페이지 하단과 이 문서에 기록합니다. 과거 갱신 기록은 당시 상태를 설명하며, 현재 표시와 다를 수 있습니다.

이번 변경은 HTML 구조·일정 수·기존 일정 보존·JavaScript 문법을 확인했습니다. ICML 2027 링크는 HTTP 200이며, 테네시대학교와 IFAC 신규 링크 3개는 일반 자동 요청에 403을 반환합니다. 해당 내용은 공식 페이지의 검색·웹 조회 결과로 대조했습니다. 로컬 파일 브라우저 미리보기는 브라우저 URL 정책으로 차단되어 배포 후 공개 페이지를 확인합니다. 추정한 월 위치는 미공개 개최일을 보장하지 않으며, 예약 전 공식 발표를 재확인해야 합니다.

## 2026-11-16 2030년까지 확장

- 기존 공개 URL을 유지하며 제목·연도 축·구분선·일정 위치 보정을 2026–2030의 5년 범위로 확장했습니다. 기존 104개 일정의 내용·링크·종료 표시는 유지하며 가로 위치만 5년 축에 맞췄습니다.
- [ICRA 2030 · IEEE RAS](https://www.ieee-ras.org/event/2030-ieee-international-conference-on-robotics-and-automation-icra-74057/): Bangkok, Thailand, Queen Sirikit National Convention Center(QSNCC), 2030-05-13–17. [일부 초기 보도](https://www.ttgmice.com/2026/07/27/thailand-wins-bid-to-host-ieee-icra-2030/)의 6/13–17과 날짜가 상충해 별표·출처 주석을 함께 표시합니다.
- IROS 2030은 TBA로 유지합니다. [CVF 목록](https://www.thecvf.com/?page_id=100)에 공개된 CVPR 2030 Denver와 WACV 2030 Waikoloa는 도시만 반영하며 날짜는 미공개입니다.
- 다른 2030 TBA는 미확인 자리표시자입니다. 예년 개최 시기를 기준으로 배치했으며 공식 날짜나 미발표 여부를 확정한 것이 아닙니다. WAFR·ECCV는 짝수 연도에 추가했고, ICCV·IFAC World Congress는 개최 주기에 따라 2030 칸을 비워 둡니다.
- 현재 27개 학회, 28개 행, 총 130개 일정입니다. 가로 스크롤 또는 드래그로 2030년을 볼 수 있습니다.
- 검증: 기존 104개 일정의 내용·링크·종료 상태 보존, 2030 추가 일정의 연도·개최 주기, 130개 카드의 최초 배치 및 화면 폭 변경 후 연도 경계 준수, JavaScript 문법을 확인했습니다.
